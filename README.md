## О проекте

Современные локомотивы генерируют сотни телеметрических параметров каждую секунду. Машинисты и диспетчеры сталкиваются с перегрузкой информацией — критичные сигналы теряются в шуме, диагностика происходит уже после отказа.

**Цифровой двойник** решает эту задачу:

- 📊 Агрегирует поток телеметрии в единый **Индекс здоровья** (0–100)
- ⚡ Обновляет данные через **WebSocket** с задержкой < 500мс
- 🔍 Показывает **Top-5 факторов** влияния на состояние
- 💡 Выдаёт конкретные **рекомендации** при каждом инциденте
- 🗺️ Отображает **маршрут** на карте в реальном времени
- 📈 Строит **живые графики** с зумом и выбором временного окна
- 📥 Экспортирует историю в **CSV**

## Быстрый старт

### Требования

- Python 3.10+
- pip

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-org/ktz-digital-twin.git
cd ktz-digital-twin

# 2. Установить зависимости
pip install fastapi uvicorn

# 3. Запустить одной командой
python main.py
```

`main.py` автоматически:
1. Запускает **generator.py** — симулятор телеметрии
2. Запускает **processor.py** — обработчик и вычисление индекса
3. Поднимает **FastAPI-сервер** (порт 8000)
4. Открывает браузер на `frontend/index.html`

### Вход в систему

```
Логин:  admin
Пароль: ktz2025
```

> Учётные данные задаются в `backend/config.json`. Смена применяется без перезапуска сервера.

## Архитектура

```
generator.py
  │  Генерирует телеметрию (4 сценария)
  │  Пишет в raw_telemetry каждые 500мс (или 50мс в highload)
  ▼
rawdata.db  (SQLite)
  │
  ▼
processor.py
  │  Читает новые строки из raw_telemetry
  │  Вычисляет health_index, статус, Top-5 факторов, рекомендацию
  │  Пишет в processed_telemetry
  ▼
server.py  (FastAPI + uvicorn)
  │  WebSocket /ws  — стримит обработанные данные клиентам
  │  REST API       — история, метрики, конфигурация
  ▼
frontend (браузер)
  │  WebSocket-клиент с EMA-сглаживанием и backoff reconnect
  │  Chart.js графики, Leaflet карта, живые виджеты
```

### Внутренняя шина событий

Сервер использует `asyncio.Queue` как шину событий между компонентами. Новые строки из БД опрашиваются с интервалом, соответствующим текущему режиму (обычный / highload), и рассылаются всем подключённым WebSocket-клиентам.

## Индекс здоровья

Индекс здоровья — интегральный показатель состояния локомотива от **0 до 100**.

### Формула

```
health = 100 + Σ(штрафы за аномальные параметры)
health = clamp(health, 0, 100)
```

### Штрафная таблица

| Параметр              | Условие             | Штраф |
|-----------------------|---------------------|-------|
| Температура двигателя | ≥ 100°C             | −30   |
| Температура двигателя | ≥ 95°C              | −20   |
| Температура двигателя | ≥ 90°C              | −10   |
| Температура масла     | ≥ 95°C              | −20   |
| Температура масла     | ≥ 88°C              | −12   |
| Давление тормозов     | < 3.5 бар           | −30   |
| Давление тормозов     | < 4.0 бар           | −20   |
| Давление тормозов     | < 4.5 бар           | −10   |
| Уровень топлива       | ≤ 10%               | −20   |
| Уровень топлива       | ≤ 20%               | −10   |
| Расход топлива        | ≥ 4.0 л/км          | −8    |
| Ток                   | > 200A              | −15   |
| Ток                   | > 180A              | −10   |
| Напряжение            | вне норм. диапазона | −8    |
| Напряжение            | вне критич. диапаз. | −15   |
| Алерт OVERHEAT        | активен             | −20   |
| Алерт LOW_PRESSURE    | активен             | −20   |

### Статусы

| Диапазон | Статус    | Цвет   |
|----------|-----------|--------|
| 80–100   | Норма     | 🟢 зелёный |
| 50–79    | Внимание  | 🟡 жёлтый  |
| 0–49     | Критично  | 🔴 красный |

Все пороги и штрафы настраиваются в `config.json` без перезапуска сервера.

## Конфигурация

Все настройки хранятся в `backend/config.json`. Изменения применяются **без перезапуска** сервера через `POST /config/reload`.

```json
{
  "health": {
    "engine_temp": {
      "critical": 100,
      "high": 95,
      "elevated": 90,
      "penalty_critical": -30,
      "penalty_high": -20,
      "penalty_elevated": -10
    }
    // ... остальные параметры
  },
  "status_thresholds": {
    "normal": 80,
    "warning": 50
  },
  "ema": {
    "alpha": 0.3
  },
  "queue": {
    "max_size": 500,
    "highload_batch": 10
  },
  "auth": {
    "username": "admin",
    "password": "ktz2025"
  },
  "history_hours": 72
}
```

### Параметр EMA

`alpha` (0.0–1.0) — коэффициент экспоненциального скользящего среднего. Меньше = сильнее сглаживание, больше = быстрее реакция на изменения.

## Highload-режим

Система поддерживает имитацию повышенной нагрузки (x10 событий/сек) без просадки UI.

**Включить через UI:** переключатель «НАГРУЗКА» в топбаре → интервал меняется с 500мс на 50мс.

**Включить через API:**
```bash
# Включить highload
curl -X POST http://localhost:8000/set_interval \
  -u admin:ktz2025 \
  -H "Content-Type: application/json" \
  -d '{"interval": 0.05}'

# Вернуть нормальный режим
curl -X POST http://localhost:8000/set_interval \
  -u admin:ktz2025 \
  -H "Content-Type: application/json" \
  -d '{"interval": 0.5}'
```

Интервал записывается в `backend/interval.cfg` и подхватывается generator.py и processor.py без перезапуска.

## Безопасность

- **Basic Auth** защищает все административные эндпоинты (`/metrics`, `/config`, `/config/reload`, `/set_interval`)
- **`secrets.compare_digest()`** — защита от тайминг-атак при сравнении паролей
- **Учётные данные** хранятся в `config.json`, не в коде; применяются сразу после hot-reload
- **Только mock-данные** — никаких реальных коммерческих данных в системе

## Сценарии симулятора

Генератор циклически проходит 4 фазы (80 тиков = 1 цикл):

| Тики   | Фаза           | Описание                                                    |
|--------|----------------|-------------------------------------------------------------|
| 0–19   | `normal`       | Скорость ~60 км/ч (синусоида), все параметры в норме        |
| 20–34  | `overheat`     | Температура двигателя → 108°C, ток → 180A, алерт OVERHEAT  |
| 35–49  | `recovery`     | Скорость снижается → 45 км/ч, температура нормализуется     |
| 50–64  | `low_pressure` | Давление тормозов → 3.2 бар, алерт LOW_PRESSURE             |
| 65–79  | `normal`       | Возврат в штатный режим                                     |
